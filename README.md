# 🚀 RhenSpace - Space Exploration Dashboard

Website bertema luar angkasa (Space Exploration) dengan UI futuristik (Cyberpunk/Neon), dilengkapi fitur pelacakan satelit dan planet interaktif.

## ✨ Fitur Utama
1. **Live Earth (NASA EPIC API)**: Menampilkan gambar Bumi secara *real-time* langsung dari kamera satelit DSCOVR milik NASA.
2. **Live ISS Tracker**: Melacak koordinat (Lintang & Bujur) Stasiun Luar Angkasa Internasional (ISS) secara langsung.
3. **Interactive Destination Cards**: Kartu planet/galaksi yang bisa diklik untuk menampilkan pop-up (Modal) berisi informasi astronomi.
4. **Smooth Scroll & Animasi**: Menggunakan AOS (Animate On Scroll) untuk transisi yang halus.
5. **Responsive Design**: Tampilan otomatis menyesuaikan di layar HP, Tablet, maupun PC.
